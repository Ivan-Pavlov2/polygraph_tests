# Инструкция по запуску тестов Playwright
## ✔️ Предварительные требования
*Перед началом убедитесь, что у вас установлен Node.js.*

Проверка установки Node.js
Откройте командную строку и выполните: 
````node --version````
````npm --version````

Если команды не работают, скачайте Node.js с официального сайта :https://nodejs.org/en
## ✔️ Установка зависимостей
Выполните в командной строке: ````npm install````
## ✔️ Настройка конфигурации
1. Расскрыть папку *componentObjects*
2. Открыть файл *table.component*
3. Заполнить *testData* своими значениями, не меняя константы
## ✔️ Установка Playwright
Выполните в командной строке: ````npx playwright install````
## ✔️ Запуск Playwright
Выполните в командной строке: ````npx playwright test --ui````
## ✔️ Отладка Playwright
Выполните в командной строке: ````npx playwright codegen https://polygraph-dev.royalsw.ru/````
## ✔️ Важно 
Все тесты необходимо выполнять по 1му и по очереди.
Запуск теста осуществляется нажатием на иконку плей, напротив названия теста.
